## Sobre o projeto

**ANUALE** é um jogo web diário baseado em uma ideia simples:

> **Descubra o ano antes que suas tentativas acabem.**

Todos os dias, uma nova pergunta é apresentada ao jogador.
A resposta é um ano específico e, a cada tentativa errada, uma nova
dica é liberada para ajudar na descoberta.

O objetivo é chegar à resposta utilizando o menor número possível de dicas.

O projeto foi desenvolvido para explorar desenvolvimento web moderno,
integração entre frontend e backend, persistência de dados, autenticação
e criação de uma experiência simples e intuitiva.

---

## Como funciona

O jogo apresenta um fato relacionado a um acontecimento histórico,
cultural ou cotidiano.

O jogador possui **até 4 tentativas**.

A cada erro, uma nova dica é liberada.

As dicas já desbloqueadas podem ser revisitadas.

### Sistema de cores

🟩 **Verde** — o dígito está correto e na posição correta.

🟨 **Amarelo** — o dígito existe na resposta, mas está em outra posição.

⬜ **Cinza** — o dígito não faz parte da resposta.
